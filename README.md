# 다슬 한글 (dasul-hangul)

모바일 우선 작가용 글쓰기 웹앱. 정적 HTML/CSS/JavaScript로 구성되어 Vercel에 바로 배포할 수 있습니다.

## 현재 포함된 기능
- 작품/챕터 생성, 이름 변경, 삭제, 순서 이동
- contenteditable 원고 편집 및 기본 서식 도구
- IndexedDB + localStorage 자동 저장
- 챕터 스냅샷 및 복구
- JSON 전체 백업 및 가져오기
- 글자 수 집계, 간단한 규칙 기반 문장 점검
- 인물·세계관 메모, 링크/이미지 자료 보관
- 목차, 인쇄/PDF 저장, PWA 기본 파일
- HWPX 내보내기 실험 기능(아직 한컴오피스 호환 검증 전)

## 배포
Vercel에서 이 private 저장소를 가져오고 Framework Preset은 Other, Build Command와 Output Directory는 비워 둔 채 배포합니다.

## 중요한 제한
현재 HWPX 내보내기는 실험용 최소 생성기이며, 표준 전체 구현이나 한컴오피스 호환성이 검증된 상태가 아닙니다. PDF 인쇄는 브라우저 인쇄 기능을 사용합니다. 글꼴 감지는 웹폰트 로딩 여부와 로컬 폰트 감지의 한계가 있으며 모든 기기에서 같은 글꼴이 보장되지는 않습니다. 오프라인 저장은 해당 브라우저/기기에 한정되므로 정기적으로 JSON 백업을 내려받으세요.

## 테스트
1. 작품과 챕터를 만들고 한글을 입력합니다.
2. 페이지를 새로고침해 원고가 복원되는지 확인합니다.
3. 백업 다운로드 후 새로고침/복원 테스트를 합니다.
4. 글자 선택 후 굵게/색상 등을 적용하고 재진입해 확인합니다.
5. HWPX를 내보낸 뒤 한컴오피스 한글에서 열어봅니다. 열리지 않거나 서식이 다르면 호환성 미완료로 기록하고 파일을 실제 원고 보관에 사용하지 마세요.
